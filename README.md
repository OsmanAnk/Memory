# Memory Game

Memory Game is a browser-based card matching game built with TypeScript and SCSS. Two players take turns flipping cards, collecting points, and trying to find the most matching pairs.

## Live Demo

[Open live demo](https://osman-annak.developerakademie.net/projects/memory/)

## Features

- Start screen with animated controller icon
- Player color selection
- Board size selection
- Two visual themes
- Theme-based card images and colors
- Card flip animation
- Score tracking for both players
- Current player display
- Exit game dialog
- Game over screen
- Winner and draw display

## Tech Stack

- HTML
- SCSS
- TypeScript
- Vite

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate into the project folder:

```bash
cd Memory
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```
